# Miku sprites

Artwork by **Canary Yellow**: https://canarypop.ciao.jp/shimehatsune.htm
Source archive: https://canarypop.ciao.jp/shimemiku.zip
Archive SHA-256: `f54ba231b7bbd2139cdd068bbbc5923d48c6b8ead3982bef92831fc66903e6ab`

All 61 character sprites and the original icon are bundled unchanged (62 PNGs,
about 1.2 MiB). This includes five alternate sprites not referenced by the
artist's behavior files: `shime2.png`, `shime3.png`, `shime34.png`, `shime35.png`
and `shime36.png`. The artist uses their `b` variants for those animations.
Hatsune Miku belongs to Crypton Future Media. The artwork is third-party content,
not relicensed as repository code. Behavior and conversion details are in
[the companion notes](../../.config/hypr/miku/README.md).
