# Monocraft console font

`monocraft.psf` is the same 13×22, 256-glyph PSF2 font installed on the test
laptop. It was rasterized from Monocraft v4.0's Nerd Font TTC at 16 pixels,
with a CP437-derived Unicode map. Keep it as an asset: the installer copies it
without requiring Python, Pillow or another font conversion tool.

Upstream: https://github.com/IdreesInc/Monocraft/releases/tag/v4.0
